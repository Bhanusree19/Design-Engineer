About

Why this exists

Design Engineer is a Figma plugin that turns selected Figma screens into React JS or React Native code and delivers it as a pull request to your own GitHub repository. You connect your own AI coding account. Each build runs on an isolated build machine, and you pay only for build minutes, the time that machine spends writing your code.

It is built and run by Hari Prasad, a product and UX designer in Bangalore with a background in computer science. The aim is to close the gap between a finished design and working front-end code, so designers and small teams review real code instead of handing off static files.
