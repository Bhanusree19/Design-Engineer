Before you build

Do I need my own AI account?

Yes. Sign in with ChatGPT through Codex, or add an API key for Claude Code, OpenCode, Gemini or OpenAI. Your provider bills that usage. We charge only for build minutes.

Where do I pay?

Choose a plan in the plugin. A secure checkout page opens in your browser, Razorpay takes the payment by UPI, card or netbanking, and your minutes appear in Figma within seconds.

What if a build fails?

You're charged only for the time it actually ran, and the rest of its reserved time comes back. Every build, finished or failed, is listed in the plugin with its exact time.

Do I have to tell it which stack I use?

No, if your branch already has an app. It reads the repo, recognises Expo, React Native, Vite, Next.js and similar setups, and picks the stack for you. You only choose when the branch is empty or holds both a mobile and a web app, and you can always change it.

Will it change my main branch?

No. Code goes to a new branch and arrives as a pull request. Nothing reaches main until you merge it.

Can I get a refund?

See the cancellation and refund policy for when refunds apply and how long they take.
